## Implemented measurement paths

### Counterfactual Evaluation

`runCounterfactualEvaluation` executes Base and Counterfactual with the same user, World and Engine. It computes a structural diff before execution and fails closed if any path outside the declared dimension changes. It records both candidate sets, overlap, rank movement, paired latent utility, hard-gate evidence and Flight Recorder hashes.

### Personalization Treatment Comparison

`runPersonalizationTreatmentComparison` consumes the frozen D2.2 bundles without reinterpretation. It validates the Treatment hash/controls, materializes `ACTUAL`, `NEUTRAL` and `OPPOSING` as authenticated twins, requires raw/derived consistency, and invokes the same V13 executor. It records V12, Semantic and final candidate differences plus lift, harm, opposing impact and component deltas.

The materializer delegates Product calls to the canonical RPCs. The isolated historical-clock adapter invokes the canonical ML RPC inside a disposable transaction. The current RPC/trigger interaction returns `NULL` and does not expose a persisted raw row to retimestamp in that fixture path; canonical derived projections are still produced and no direct projection write occurs. The runner records this as a bounded timing limitation: historical raw-event age is not certified by this smoke and must remain visible in the later D3-A result metadata.

### Remix Evaluation

`runRemixEvaluation` first executes an ordinary Decision, captures the shown Spot IDs, and invokes V13 a second time with exactly those IDs as `excludeSpotIds`. It records repetition, overlap, new candidates, utility movement, fallback, memory contribution, starvation and hard-gate state. It does not implement a Lab Remix policy.

### Explanation Alignment

`runExplanationAlignment` evaluates existing `human_reason` and structured candidate evidence. It derives claimed reasons from current copy, verifies them against observable request/candidate evidence and the actual fusion components, and classifies `ALIGNED`, `PARTIALLY_ALIGNED`, `MISLEADING` or `UNSUPPORTED`. Missing explanations are `UNSUPPORTED`, never PASS. No new explanation or LLM judge is introduced.
