# D4.3 AI Decision Reranker Experiment

## Executive summary

D4.3 ended **STOPPED EARLY** after the Pilot. No Full Run was executed. The AI reranker produced valid, eligibility-safe structured rankings and a positive Pilot NDCG@10 signal, but the frozen Pilot Proceed gate was internally unsuitable for a pure Top-10 reorder: it required two positive ranking metrics even though Mean Utility@10 and Precision@10 cannot change when the same ten candidates are merely permuted. The gate failed and was not changed after seeing results.

This is diagnostic evidence, not a recommendation to integrate AI into the product. Scientific validity is **FAIL** because of the unsuitable gate and because no immutable pre-run source/config freeze had been sealed before the live stages. A post-stop evidence freeze preserves exactly what ran without claiming pre-run certification.

## 1. Experiment architecture

The experiment uses the canonical Wave-1 eligibility and current candidate path. A compact AI layer receives exactly ten already eligible candidates and may only reorder them. Deterministic validation rejects unknown IDs, duplicates, missing IDs, invalid ranks, invalid scores, or invalid reason codes. Invalid model output falls back to the Wave-3C.1 control. Retrieval, Taste learning, eligibility, databases, and product code are unchanged.

## 2. Model and configuration

- Model: `gpt-5.6-luna`
- Reasoning: `low`
- Candidate count: 10
- Maximum input tokens: 1,600
- Maximum output tokens: 1,600
- Timeout: 30 seconds
- Temperature: model default
- Prompt: `backyrd-ai-decision-reranker-prompt-v1`
- Input contract: `backyrd-ai-decision-input-v1`
- Output contract: `backyrd-ai-decision-output-v1`

The single-model choice follows the cost-sensitive staged experiment requirement. No model zoo or holdout-driven model choice was used.

## 3. Candidate input contract

Allowed input is limited to Structured Intent, current Context, a compact Current Taste projection with Confidence, eligible observed Spot Intelligence, and retrieval rank. Latent Truth, evaluation utility, Golden labels, future outcomes, raw personal history, PII, and private Trust evidence are prohibited. Latent Truth is used only after ranking by the evaluator.

## 4. Structured output contract

The response is strict JSON Schema containing every supplied Candidate ID exactly once, an integer rank sequence, bounded fit and confidence, bounded reason codes, and overall confidence. Free text is not a ranking authority. Candidate invention, removal, duplication, or mutation invalidates the response.

## 5. Budget guardrails

External calls require both `DECISION_LAB_OPENAI_API_KEY` and a positive `DECISION_LAB_AI_BUDGET_USD`. Missing configuration stops before a call. Every call checks actual prior spend plus worst-case projected call cost. The local cache is excluded from Git and keyed by model, model config, prompt/contract versions, runtime input, and Candidate IDs.

## 6. Measurement-integrity incidents

- **D4.3-MI-001:** The initial 1,100-token input cap was smaller than compact input plus strict schema (1,234–1,564 estimated tokens). It stopped before external calls. The payload was compacted and the cap corrected to 1,600.
- **D4.3-MI-002:** The initial 500-token output cap truncated all 15 first live Smoke responses. Cost: USD 0.0104938. Invalid responses were not used. The cap was corrected to 1,600, invalid-cache writes were prohibited, and Smoke restarted from the beginning.
- **D4.3-MI-003:** The Pilot Proceed gate requires two positive ranking metrics. With the same ten candidates evaluated at K=10, Mean Utility@10 and Precision@10 are set-invariant; only NDCG@10 measures order. The Full Run stopped. The gate was not changed after results.
- **D4.3-MI-004:** A pre-run immutable source/config freeze was not sealed before live Smoke/Pilot. The post-stop freeze is evidence preservation only. It cannot retroactively certify the run.

## 9. Full Run

Not executed. The Pilot gate failed. Locked Holdout remained unused by D4.3.

## 10. Personalization and context

ACTUAL/NEUTRAL/OPPOSING were executed in Smoke and Pilot, but the stopped, scientifically invalid Pilot cannot support a Personalization or Contextual-Intelligence verdict. These remain **INCONCLUSIVE**. Current Intent authority and eligibility integrity passed structurally.

## 11. Failure modes and fallback

Observed failures were pre-call input-cap rejection and output truncation. No unknown Candidate, duplicate Candidate, eligibility override, provider error, or budget overrun was accepted. Deterministic fallback remained available. Invalid results never affected evaluated ranking.
