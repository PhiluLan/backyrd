# N5.6 Change Ledger Contract

Version: `backyrd-n5-6-change-ledger-v1`

Every node update appends a hash-addressed record with user, node, before/after state, reason, evidence-chain reference, time, provenance and a human-readable explanation. Allowed reasons are node creation, evidence addition, contradiction addition, polarity change, confidence change and drift update.

The ledger is immutable and reconstructable. Corrections append rather than rewrite. A production store must serialize updates per user, use transactional compare-and-swap/version checks, and preserve the source contract identity. Concurrent duplicate delivery is idempotent; conflicting identity fails closed. Late/out-of-order events trigger deterministic rebuild of the affected user/node scope.

The North Star fixture produces 4,270 ledger entries. This is deliberately an audit timeline, not a UI feed. Human review consumes milestone summaries; complete entries remain in the sealed artifact.

Deletion removes source evidence and creates a new lawful rebuild. Audit metadata may retain only the minimum non-personal proof required by policy; it cannot retain a usable deleted preference.
