# Mobile Visual Fidelity — final closure

## Product boundary

This change is visual and media-only. It does not change Decision ranking, N3/N4/N5/N6, canonical N2, User Intelligence, onboarding authority, continuation, or the Build-50 runtime contract.

## Reference alignment

The supplied Home reference is implemented as an editorial composition rather than a generic card dashboard:

- black canvas, acid location context, off-white condensed system display type;
- two-line `WOHIN GEHT’S / HEUTE?` signature with a reusable rough pink marker;
- outlined Decision input with a distinct pink arrow action;
- honest quick-context Moments (not fictional people or social activity);
- numbered discovery section with immersive photography and type over image;
- shared pink editorial rule and acid metadata;
- floating black navigation with `Entdecken / Für jetzt / + / Karte / Momente`.

`BASEL ENTDECKEN` replaces `GERADE ANGESAGT`: the current source is Product discovery, not a measured trend signal.

The Decision input uses the same `DEIN / JETZT.` hierarchy, marker treatment, acid `WO` and `WAS / MOOD` labels, minimal surfaces, and a flat pink action. The result keeps neutral `Weiter` visually primary while feedback and Route remain secondary.

## Responsive validation

The actual exported app was rendered at 320 × 568, 390 × 844, and 430 × 932 CSS pixels. The 390 px capture was compared directly with the supplied reference. The headline was resized after the first capture exposed truncation; the final render preserves both complete lines. The 320 px variant uses shorter honest search copy and a horizontally discoverable Moment row. Bottom navigation stays above content and respects the supported safe-area layout.

Native iOS uses the project-safe system face `Avenir Next Condensed`; Android uses `sans-serif-condensed`. No unlicensed font was added.

## Reusable visual primitives

- `MarkerStroke`, `EditorialSectionHeader`, `EditorialRule`, `EditorialMeta`
- `SpotArtwork` with loading, disk/memory cache, privacy-safe error diagnostics, and branded fallback
- shared Home, Decision, Map, nearby, and Spot-detail image rendering

## Intentional limits

- The current Product does not have real social Moment avatars on Home. Quick Decision contexts are shown as icons and labelled honestly.
- Some Production Spots genuinely have no canonical photo. They receive the branded fallback; no photo or social proof is fabricated.
- This closure does not mutate stale media rows. ELYS currently has an unreachable stored object and should be corrected through the normal media-authoring workflow.
