# N5.6.1 Decision-Specific Sufficiency Contract

Version: `backyrd-n5-6-1-decision-sufficiency-v1`

## Required separation

- `overallUserKnowledge`: how deeply Backyrd knows the person overall;
- `momentClarity`: how clearly the current desire is specified;
- `contextKnowledge`: matching social-context evidence;
- `placeTypeKnowledge`: matching domain evidence;
- `finalPersonalizationSufficiency`: how much applicable User knowledge supports this Decision.

No single component, number of selected nodes, Occasion Pattern, or overall maturity can independently produce `HIGH`.

## Components

The deterministic decomposition exposes overall maturity, Moment clarity, Context knowledge, temporal knowledge, Place-Type knowledge, Global fallback strength, Occasion support, relevant evidence depth, projection confidence, relevant signed breadth, contradiction penalty, fallback penalty, and mean fallback depth.

Global fallback contributes only a bounded fraction. An explicit social context without matching social-context history incurs a penalty. COLD, EARLY, and DEVELOPING states remain conservatively bounded.

## Labels

- `HIGH`: score ≥ `0.72` and applicable evidence supports it;
- `PARTIAL`: score ≥ `0.38`;
- `LOW`: some or no applicable knowledge, below `0.38`;
- `UNKNOWN`: no selected User knowledge for a COLD/unsupported profile.

Machine-readable reasons include `HIGH_CONTEXT_SUPPORT`, `MATCHING_OCCASION_SUPPORT`, `PARTIAL_CONTEXT_SUPPORT`, `PARTIAL_PLACE_TYPE_BACKOFF`, `PARTIAL_GLOBAL_FALLBACK`, `LOW_CONTEXT_HISTORY`, `LOW_MOMENT_CLARITY`, `PLACE_TYPE_UNKNOWN`, `NO_APPLICABLE_USER_EVIDENCE`, and `COLD_USER_NO_DURABLE_KNOWLEDGE`.

## Honest uncertainty examples

- DEEP + unsupported Family Context → `LOW/PARTIAL`, never inherited `HIGH`.
- DEEP + clear Solo Context + exact recurring occasion → may be `HIGH`.
- DEEP + vague Moment → `LOW`, even with a rich User Card.
- COLD + clear Moment → clear N3 Moment but `UNKNOWN/LOW` User personalization.
