# N5.6.2 World Contract

Version: `backyrd-n5-6-2-realistic-longitudinal-world-v1`

Status: implemented for preflight; **not promoted to official World Freeze because N5.6.2-ED-001 stopped the treatment**.

## Population and time

- Frozen seeds: `56201`, `56202`, `56203`.
- Twelve stable User IDs per seed.
- Eight long-term users, two developing users, one long-account/light user and one cold control.
- Account spans range from one to 36 months; maturity is derived from evidence, not age.
- Cadence is non-uniform and includes regular, weekend-heavy, bursty, seasonal, heavy-new and light patterns.

## Product-observable sessions

Supported session classes are Decision browse, Decision commit, direct map, search/reservation, ignored results, repeat favorite and shared-link/low-value interaction. A session may contain canonical requests, result exposure, Spot open, Save, navigation, reservation, verified visit and optional explicit feedback. Missing outcomes are first-class.

All Engine events validate against the N2 memory event contract. Group compromise, logistics, noise, opportunity sets and hidden satisfaction remain evaluator-only generation context; they are not added as private runtime facts.

## Users and behavior

The population covers social/nightlife, family, price-context, premium/design, social-context reversal, repeat behavior, travel, developing and sparse controls. Latent tendencies are probabilistic and may produce atypical behavior. Four or more long-term specifications contain gradual drift; temporary phases are separately modeled.

## Spot universe

- Four cities: Basel, Zurich, Copenhagen and Berlin.
- Eight controlled Place Types.
- Two to six Concepts per Spot.
- N4-compatible Concept confidence includes high, medium and below-attribution-boundary values.
- Spot quality is distinct from User fit.
- Concept bundles vary; no final learned scores are scripted.

## Privacy and scientific boundary

Engine inputs contain no latent tendency, hidden satisfaction, evaluator label, future outcome, oracle or Ground Truth. Location is city-level and session-scoped. All events use granted synthetic consent for the defined personalization purpose. No real User data is used.
