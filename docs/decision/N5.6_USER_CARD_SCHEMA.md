# N5.6 Full User Card Schema

Version: `backyrd-n5-6-user-card-v1`

The Full User Card is an internal, consent-scoped read model. It is not an N6 payload and is never a replacement for canonical Memory.

## Top-level fields

| Field | Meaning |
|---|---|
| `userId`, `asOf`, `version`, `userCardHash` | stable identity and reproducible snapshot |
| `maturity` | COLD/EARLY/DEVELOPING/KNOWN/WELL_KNOWN/DEEP from independent evidence depth |
| `memorySummary` | event, chain, independent session/spot and outcome counts plus time span |
| `nodes` | signed GLOBAL, PLACE_TYPE and CONTEXT intelligence |
| `behavioralPreferences` | non-taste tendencies such as exploration, kept separate from taste |
| `occasionPatterns` | repeated evidence-backed context signatures |
| `contradictions` | explicit positive/negative support conflicts |
| `uncertainty` | unknown concept coverage and incompleteness |
| `evidenceChainIds` | reconstructable links to source evidence |
| `boundaries` | no ranking, no N6, no raw history, city portability |

## Signed node

Every node contains `concept`, `scope`, signed `affinity`, `confidence`, `polarity`, positive and negative evidence totals, recent and long-term affinity, trend, independent evidence depth, provenance, evidence references, and contradictions. A negative preference is therefore first-class rather than inferred from absence.

`confidence` measures support quality and independence. It is not preference strength. `affinity` measures direction and strength. `UNKNOWN` remains valid even for a mature user.

## Graph semantics

Logical edges are `SUPPORTED_BY`, `SCOPED_TO`, `CONTRADICTS`, `DERIVED_FROM`, and `SUPERSEDED_BY`. A graph database is not required. The canonical representation is relational/document-shaped, hashable, deletable per user, and reconstructable from Memory plus frozen contracts.

## Maturity

Maturity requires all configured dimensions: independent sessions, outcome-bearing chains, and confident nodes. Event count alone never promotes a user. DEEP does not mean complete; it means broad and repeated evidence under the frozen model.
