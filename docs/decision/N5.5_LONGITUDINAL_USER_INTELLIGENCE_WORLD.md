## Executive result

N5.5 replaces the earlier thin N6A test-profile population with a deterministic, N2-native longitudinal world. Nine persistent users yield 54 N3→N5 decision projections, including 40 high, 6 medium and 8 low diagnostic personalization-opportunity arms. All pre-frozen integrity and projection gates passed.

This is evidence that the **test world** can exercise rich user knowledge and N5 relevance selection. It is not evidence that any AI/ranking layer improves decisions, and it does not revise any historical N6A verdict.

## Architecture

Canonical Memory events are the sole learning input. N2 constructs its ledger, Wave-3B.1 taste rows, context/place-type slices, contradiction records, patterns and timeline. N3 then builds a temporary current moment. N5 selects only contextually applicable derived intelligence and records suppression and sufficiency. The evaluator-only behavioral generator never crosses into those inputs.

## What was measured

The run includes Family Sunday, Friends Friday, Date Evening, Solo Afterwork, a Copenhagen arrival and a broad/uncertain request for each user. It tests:

- context- and place-type-specific learning;
- positive, negative and conflicting history;
- early/developing/mature/cold lifecycle behavior;
- same user across different moments;
- different users in the same moment;
- current intent overriding incompatible positive history while allowing a matching negative avoidance signal;
- portable profile use in Copenhagen with no local visit history;
- bounded N5 output, provenance and latent-truth isolation.
