# N5.5 — Longitudinal User Intelligence World Contract

Status: **FROZEN — LAB ONLY**  
Production: **UNCHANGED**

## Purpose

N5.5 supplies a realistic, deterministic synthetic world for validating what N2 can learn over time and what N5 can selectively project for a current decision. It is not a ranking test, an N6 test, or Production data.

```text
Evaluator-only behavioral generator
        ↓ emits only legitimate first-party events
N2 canonical Memory Event Contract
        ↓
N2 User Intelligence / frozen Wave-3B.1 Taste Engine
        ↓
N3 Current Moment
        ↓
N5 Relevant User Projection
        ↓
diagnostic validation only
```

## Population and timeline

The frozen world contains nine persistent synthetic users: Explorer, Social/nightlife, Family planner, Date/couple, Budget conscious, Premium/design, Developing café user, Cold user, and `NORTH_STAR_EXPLORER_01`.

The seven mature/long-term users hold 79–109 canonical memory events across 78–109 independent sessions and 46–47 distinct spots. Their histories span 270 days. The developing user has nine events/sessions; the cold user has one neutral request event and no learnable preference evidence.

All events have a stable ID and idempotency key, granted personalization consent, provenance, a minimized N2 moment signature and N2-supported Spot concepts. Events are outcome/explicit-feedback/onboarding classes inside N2 retention; no raw historical migration, client fabrication or non-canonical event type is used.

## Evidence and truth boundary

Archetypical behavior exists in an evaluator-only structure. It determines which legitimate events the world generator emits, but is never an N2, N3 or N5 runtime input. The engine-input serialization is scanned for latent-truth/oracle/evaluation fields before the run. The evaluator reference has its own hash and is excluded from projections.

The world deliberately includes positive and negative evidence, repeated independent sessions and spots, multiple place types, contextual evidence, recurring signatures, two drift/contradiction users (Explorer and `NORTH_STAR_EXPLORER_01`) and a Copenhagen current-moment case. It does not claim that any individual real user behaves this way.

## Lifecycle snapshots

For each user N5.5 rebuilds N2 from four immutable prefixes: Day 0/onboarding, early, developing and final mature/long-term. No final profile is hand-written. The only input to each rebuild is the corresponding canonical event prefix.

## Explicit non-goals

- no Spot ranking, retrieval, Candidate pool or Ground Truth;
- no AI call, N6 invocation, prompt/model work or quality verdict for N6A;
- no Product database, migration, production access or mutation;
- no change to N2, N3, N4, N5 or Wave-3B.1 semantics.
