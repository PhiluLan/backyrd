# Phase 3B Readiness

Phase 3A stellt Contracts, Authority, Interpretation Provenance, Domain-Trennung, deterministischen Reducer, Rebuild-Parität, neutrale Decision Projection und Lifecycle-Löschung bereit.

Phase 3B darf erst nach Product-/Privacy-Freigabe beginnen. Verbindlich deferred bleiben: echte Signalstärken, finale Attribution, Recency/Decay, Maturity-/Sufficiency-Schwellen, Product Context Allowlist, Retention, Product Wiring, Shadow Traffic und Decision-Einfluss.

Später und nicht optional: Long-Term-/Recent-/Contextual-Reducer-Kalibrierung, Practical Behavior, Direct Spot Policies, Nutzertransparenz/Korrektur, Embeddings, Similar-User-/Collaborative-/Social Intelligence, kontinuierliche Modellaktualisierung und Evaluation gegen reale Outcome-Qualität.
