# Retention Decision Package

Es wurden keine Aufbewahrungsfristen festgelegt. Alle Klassen besitzen `duration: null`; Source-Code-, Fixture-, Infinite- oder Client-Defaults sind verboten.

Offene Freigaben:

- **Founder:** Welche interne Rehearsal-Nachvollziehbarkeit ist produktfachlich erforderlich?
- **CTO:** Welche technischen Lösch- und Auditnachweise sind je Store erforderlich?
- **Legal:** Welche gesetzlichen Mindest-/Höchstfristen und Exportpflichten gelten je Datenklasse?

Bis zur gemeinsamen Freigabe bleibt der Status `NOT_CONFIGURED_PENDING_FOUNDER_CTO_LEGAL` und blockiert jede Production-Aktivierung.
