# Noch notwendige Freigaben

Keine der folgenden Fragen wird durch Week 1 entschieden:

1. Founder/CTO: welche bereits kalibrierten Regeln in einen späteren Runtime Release aufgenommen werden.
2. Legal/CTO: Rechtsgrundlage, konkrete Dauer und Löschtrigger je Retention-Klasse.
3. Privacy/Legal: Umfang und Darstellungsform gesetzlich erforderlicher abgeleiteter Exportdaten.
4. CTO/Security: konkrete Store Executor-, Queue-, Retry-, Audit- und Incident-Verträge.
5. CTO: messbare Withdrawal-Latenz und Erasure-SLA erst bei vorhandenem Runtime/Store Executor.
6. Product/CTO: autorisierte Product Producer und serverseitige Event-Bindings.
7. Decision/CTO: separater späterer Projection-Consumer; Ranking und Eligibility bleiben ausgeschlossen.

Jede Aktivierung benötigt einen neuen versionierten Release und einen unabhängig akzeptierten Trust Anchor. Dieses Paket kann nicht durch Relabeling aktiviert werden.
