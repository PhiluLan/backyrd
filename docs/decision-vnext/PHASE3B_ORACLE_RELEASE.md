# Phase 3B Founder Oracle Release

Der Release enthält 28 Founder-approved strukturelle Context-Szenarien (27 geforderte plus den korrigierten isolierten Zeit-Flip). Founder-Approval autorisiert Erwartungen, aber weder Production noch Ranking-Gewichte oder Product-Qualität.

Jedes Oracle bindet Scenario, Founder-Decision-Referenz, exakte Context-Änderung, Candidate-Tier-Effekt, relative Richtung, Clarification und Explanation-Invarianten. Authority- und Trust-Kataloge sind getrennt, eindeutig und rekursiv gehasht. Der kombinierte Release besitzt einen separaten Ed25519-Trust-Root.

Replay rekonstruiert jeden Scenario Report aus der akzeptierten Capability und vergleicht anschließend den vollständigen Workbench byte-identisch. Der korrigierte `midday-vs-late-evening`-Flip ändert ausschließlich `context.time.local`. `device-basel-target-zurich` stellt explizites Zielgebiet statt einer irreführenden „same request“-Behauptung dar.
