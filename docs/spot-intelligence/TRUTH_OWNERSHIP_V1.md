# Spot Intelligence Truth Ownership V1

| Data | Owner | May propose | May publish/accept | Forbidden shortcut |
| --- | --- | --- | --- | --- |
| Discovery candidate | City Bootstrap operational schema | OSM/Google adapters | service pipeline | treating it as a Product Spot |
| External evidence | normalized evidence/source record | authorized provider or official website | service pipeline stores evidence only | raw provider payload retention |
| Spot identity | `spots` plus external identity registry | identity reconciler | service-only publication RPC after hard gates | name-only merge or client write |
| Canonical facts | existing Gold proposal/acceptance system | Research Agent | authorized Admin acceptance path | AI output directly writing Accepted Facts |
| N4 dimensions | existing derived N4 contracts | canonical source-bound facts | existing deterministic rebuild | bootstrap/AI direct N4 write |
| Offering/Purpose | existing Human Spot Intelligence contract | existing authoring workflow | existing authorized path | deriving from provider category alone |
| Decision ranking | existing Decision Engine | none in this workstream | existing Decision contracts | candidate priority affecting `final_score` |
| Community evidence | future evidence adapter | trusted community signal | future weighted reconciliation | direct overwrite of Spot truth |
| Owner evidence | future Owner adapter | verified Owner declaration | existing/future authorized reconciliation | Owner self-ranking or unreviewed overwrite |

Evidence strength and a moderation or authoring decision are separate records. A model result is evidence/proposal material only. `UNKNOWN` stays unknown. Conflicts preserve both evidence lineages and route to review; weak evidence cannot overwrite stronger accepted truth. Negative or closure evidence requires explicit source support and does not silently archive a Spot.

The new publication RPC writes only core identity and a source lineage record. Existing triggers may enqueue embeddings/distribution work. It never writes `backyrd_spot_accepted_facts_v1`, N4, reviews, moments, Decision history, analytics history, or User Learning.
