# @backyrd/world-knowledge-core

Pure TypeScript foundation for versioned Spot knowledge, append-only claims, deterministic resolution, qualitative trust, temporal state, bounded derived knowledge, and the sanitized `WorldKnowledgePort`.

This package is not connected to Production storage or any Decision consumer. Architecture and contract documentation starts at [`docs/world-knowledge/README.md`](../../docs/world-knowledge/README.md).

```bash
npm run world-knowledge:typecheck
npm run world-knowledge:test
```
